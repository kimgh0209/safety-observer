# ASSA+ 안전관찰 도우미

휴대폰으로 현장 사진을 찍으면 AI가 관찰사항, 안전/불안전 상태, 제안/건의사항 초안을 작성합니다.
서버 없이 `index.html` 한 장으로 동작하는 정적 웹앱입니다(GitHub Pages 호스팅).

## 사용법
1. 휴대폰 브라우저에서 Pages 주소 접속 → 설정에서 Anthropic API 키 입력(기기에만 저장)
2. 촬영/앨범 선택 → 장소 설명 입력(선택) → 분석하기
3. 항목별 복사 버튼으로 ASSA+ 등록 화면에 붙여넣기
4. 홈 화면에 추가하면 앱처럼 사용 가능

## 주의
- API 키는 코드/저장소에 넣지 마세요. 브라우저 localStorage에만 저장됩니다.
- 사진이 Anthropic API로 전송됩니다. 사내 보안 정책을 확인하세요.
- AI는 사진에 보이는 것만 판단합니다. 반드시 현장 확인 후 보완하세요.
